# DAMPSOLUTIONS - Sistema de Gestión de Formación

**Desarrollado por: Desteveco - David Estévez Couñago**

## Descripción del Proyecto
DAMPSOLUTIONS es una aplicación desarrollada en Microsoft Power Apps diseñada para la **gestión, control y seguimiento integral de la formación** de los empleados de una empresa ficticia. 

El sistema permite supervisar de manera eficiente la matriz de competencias de la organización, facilitando la consulta de formación registrada, el control de vigencias y la gestión documental de exámenes y certificados de asistencia.

## Características principales
* **Gestión de Matriz de Formación:** Visualización clara del estado de formación por operario, curso y área.
* **Control de Vigencias:** Cálculo automático de la validez de los cursos basándose en las fechas de creación y periodos de caducidad.
* **Gestión Documental:** Integración con SharePoint para la carga y visualización de PDFs de exámenes y registros de asistencia.
* **Flujos de Trabajo:** Validación de requisitos de formación (Evaluaciones, ILUO, Adjuntos) para determinar el estado de "Realizado".
* **Interfaz Adaptativa:** Diseño optimizado para la consulta rápida de datos operativos en entornos industriales.

## Tecnologías Utilizadas
* **Microsoft Power Apps:** Desarrollo de la interfaz y lógica de negocio.
* **Microsoft SharePoint:** Almacenamiento de registros, datos de personal y archivos adjuntos.
* **Git:** Control de versiones del código fuente y manifiestos de la aplicación.
